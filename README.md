# Bakalarska praca - Inferencia a vizualizacia vysledkov


### Ako spustit inferenciu
Kliknite na tlacitko `Open in Colab`  
Prihlaste sa svojim google uctom (Google Colab je oficialna sluzba poskytovana firmou Google)  
Zmente nastavenie Runtime > Change runtime type > hodnotu Runtime type na `Python 3` a vyberte potvrdte tlacidlom `Save`  
Odporucany krok: Pre rychlejsiu inferenciu odporucam zmenit nastavenie Runtime > Change runtime type > `Hardware accelerator` na hodnotu `T4 GPU` a vyberte potvrdte tlacidlom `Save`  
Spustenie inferencie je vykonane stlacenim tlacidla `Run all`
